# Paper-facing result summaries

The CSVs in this directory are compact tables transcribed from the revised preprint and executed notebook outputs. They are intended for quick inspection and figure/table reproduction.

They are **not** a replacement for the per-word outputs created when the notebooks are rerun. Those larger output directories were not among the files supplied for this repository package, so this archive does not pretend to include them.

For provenance, use the executed notebooks in `notebooks/paper/`.
